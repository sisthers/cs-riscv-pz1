# ВС, ПЗ1 - RISC-V

Кузин Николай, М3О-118СВ-26, номер в списке 8

Запускал в RARS 1.6.

- `task_a.asm` - вводим x, выводит 1 если x = 8, иначе 0
- `task_b.asm` - вводим x, выводит числа от min(x, 118) до max(x, 118) с шагом 8
- `task_c.asm` - заполняет массив из 16+8 = 24 чисел с клавиатуры, останавливается на 0. В конце печатает сколько считал и сам массив (для проверки)
